scratchpad_

scratchpad_ is a replacement for Notepad, focused on plain text because so many good text editors drift toward becoming code editors. This is the project management console used to build it.

  1. Keep it plain. Scratchpad is for fast, reliable text work first, without treating every note as code.
  2. Prove it scales. The editor must open large files, keep lots of them available, then search and edit them without slowing down.
  3. Build for one user. The console is highly opinionated because Scratchpad has a target user base of one.

What each tab measures

Overview
Shows the score across Quality, Capacity, and Correctness, plus the FPS score that keeps redraw speed visible.
Telemetry
Monitors Scratchpad while it is running, including sessions, tabs, buffers, diagnostics, and files.
Quality
Measures code quality goals that keep Scratchpad easy to maintain, fast to change, and reliable.
Performance
Checks whether the editor can open large files, handle many open files, then search and edit them.
Correctness
Runs tests that lock in functionality and catch regressions when one area is fixed or improved.
Map
Shows the inputs, outputs, dependencies, and risk concentration for each module.
Log
Records the Quality, Performance, and Test tasks that ran, plus the JSON artifacts they created.
